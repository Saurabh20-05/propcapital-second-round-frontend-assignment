# PropCapital – Landing Page Redesign

A modern, responsive redesign of the **PropCapital** website, developed as part of the Second Round Technical Evaluation – Frontend Development Assignment.

## About the Project

This project focuses on improving the original PropCapital landing page with a modern UI, better user experience, responsive layouts and interactive frontend elements while maintaining the original brand identity.

## Technologies Used

- HTML5 – Website structure
- CSS3 – Styling, layouts, animations and responsiveness
- JavaScript (Vanilla JS) – Interactive functionality and dynamic content

## Key Features

- Modern and responsive landing page design
- Interactive navigation bar
- Hero section with property search
- AI-powered property matching demo
- Property listings with filtering functionality
- Interactive property cards
- EMI calculator
- Property-related information sections
- FAQ section
- Lead enquiry form
- Responsive design for desktop, tablet and mobile devices
